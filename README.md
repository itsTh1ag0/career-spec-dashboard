# Career Spec Dashboard — Thiago Gusmao

Single-page Apple Spec-style career showcase.

**Goals**
- A) Embed / showcase on LinkedIn profile
- B) Shareable URL/artifact for recruiters → "Wow moment" during interviews

**Style**
- Apple product Spec sheet / device presentation aesthetic
- Clean, premium, metrics-focused (not resume dump)
- Device mockup (iPhone / Mac / multi-device) framing the dashboard

**Core Metrics to Surface** (editable data layer)
- Years of experience / roles
- Companies worked
- Countries / markets covered (LATAM, AMER, EMEA)
- Skills & tools count / categories
- Co-workers / team sizes (approx)
- Key impact numbers (MTTR reduction, escalations handled, etc.)
- Languages, timezones, compensation baselines

**Tech Direction** (to be refined)
- Single page: HTML/CSS/JS or lightweight Next.js / Astro
- Pure CSS device frames or SVG mockups
- Data from JSON / config for easy updates
- Deployable as static site (Vercel / GitHub Pages)

**Shared Context**
- Engineering Workstyle & Job Analysis docs in Google Drive
- Crosswalk: careertaskforce
- Compensation baseline: $4k USD/mo (flexible by schedule)
